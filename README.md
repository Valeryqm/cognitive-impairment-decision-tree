# Classifying cognitive impairment with a decision tree (R · tidymodels)

*[Versión en español → README.es.md](README.es.md)*

A supervised-learning project that classifies 150 patients into three clinical groups — **healthy**, **mild cognitive impairment (GDS 3)** and **moderate cognitive impairment (GDS 4)** — from eight binary neuropsychological indicators. The goal is a model that is accurate **and** readable: a short set of rules a clinician could follow.

> **Academic project.** Coursework for *Aprendizaje Automático Supervisado* (2025-26). It is not a diagnostic tool.

## Key results

| | |
|---|---|
| Data | 150 patients, 3 balanced groups (50 each), 8 binary predictors (preserved / impaired) |
| Split | 80/20 stratified, `set.seed(123)` → 120 train / 30 test |
| Tuning | random grid of 20 combinations, stratified 10-fold CV |
| Selected tree | `cost_complexity ≈ 2.4e-10`, `tree_depth = 7`, `min_n = 14` |
| CV accuracy | 0.950 (SE 0.014) |
| **Test accuracy** | **30/30 (100%)** — exact 95% CI: 88.4–100% |

**The tree uses only three questions:**

1. Is verbal memory impaired? **No → healthy.**
2. If it is: is verbal fluency impaired? **Yes → GDS 4.**
3. If fluency is preserved: is working memory impaired? **No → GDS 3**, **yes → GDS 4.**

### Comparison with other models (10-fold CV, same folds and recipe)

| Model | Accuracy | Kappa | Sensitivity | Specificity |
|---|---|---|---|---|
| Decision tree | 0.950 ± 0.014 | 0.925 | 0.950 | 0.975 |
| Random forest (500 trees) | 0.950 ± 0.014 | 0.925 | 0.950 | 0.975 |
| k-NN (k = 5) | 0.842 ± 0.036 | 0.762 | 0.842 | 0.921 |

The single tree matches the random forest while remaining fully interpretable.

## Reproduce it

Requires R ≥ 4.2.

```r
install.packages(c("tidymodels", "foreign", "rpart", "rpart.plot",
                   "ranger", "kknn", "scales", "forcats"))

# from the repository root
source("R/arbol_decision.R")
```

The script prints the tuning results and test metrics and writes all figures to `figures/`.

## Method

- **Preprocessing:** `recipes` — `step_dummy()` on all nominal predictors (e.g. `verbal_memory_impaired`).
- **Model:** `decision_tree()` with the `rpart` engine; `cost_complexity`, `tree_depth` and `min_n` tuned.
- **Validation:** stratified 10-fold CV for tuning; final fit with `last_fit()` on the untouched test set.
- **Metrics:** accuracy, Cohen's kappa, macro-averaged sensitivity and specificity.

## Limitations and next steps

- Small sample (n = 150), artificially balanced, so it does not reflect real clinical prevalence. A 30-case test set gives a wide interval even at 100% accuracy.
- Binary predictors discard information about *how* impaired each domain is; continuous test scores would be richer.
- The top five configurations tie at 0.95 CV accuracy, so `select_best()` picks among ties arbitrarily. The one-standard-error rule (`select_by_one_std_err()`) would favour the simplest tree.
- The tree's hyperparameters were tuned on the same folds used for the model comparison, while the random forest and k-NN use defaults, which is slightly favourable to the tree. Nested CV would make the comparison fairer.
- Next: gradient boosting, a regular grid search, and imbalanced real-world data.
